# HydraFilmes

HydraFilmes é um aplicativo de entretenimento em fase de testes, desenvolvido como Progressive Web App (PWA) e distribuído como aplicativo Android.

## Status
🚧 Em testes  
✅ Funcional

## Objetivo
Oferecer uma interface moderna e responsiva para acesso a conteúdos audiovisuais incorporados de plataformas públicas.

## Aviso Legal
O HydraFilmes não hospeda vídeos próprios. Todo o conteúdo é incorporado de plataformas externas públicas.
